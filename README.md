# Clipboard

A native macOS clipboard and character panel inspired by Windows 11's Win+V panel. Apple Silicon, macOS 14 or later. Uses native Liquid Glass on macOS 26 and native vibrancy on older supported systems.

## Install

1. Quit any previous version and remove its app from Applications. Unzip `dist/Clipboard-1.2.zip` (or `dist/Clipboard.zip`), drag Clipboard to Applications, and open it.
2. Settings opens on first launch. Choose **Enable** beside Accessibility, then enable Clipboard in System Settings > Privacy & Security > Accessibility. This allows selecting an item to paste into the previous app. Without permission, selection copies the item and you paste with Command+V.
3. Press **Command+Shift+V** from another app. Or click the clipboard icon in the menu bar. There is intentionally no Dock icon.
4. Click the shortcut field in Settings to record a different shortcut. Enable Launch at login if wanted.

This is a locally built, ad hoc signed app, not a notarized App Store release. If macOS blocks opening a transferred copy, use System Settings > Privacy & Security > Open Anyway for this app. Do not disable Gatekeeper. Replacing an ad hoc signed build can require reauthorizing Accessibility.

If macOS asks whether Clipboard may read clipboard contents, allow access for clipboard history to work. These permissions are granted by you; the app cannot grant them itself.

## Features

The panel uses compact Windows-style tabs and cards, a neutral graphite accent, direct pin buttons, and matching continuous corner masks over native Liquid Glass. Source attribution is available as a tooltip and through search. Drag the panel's upper edge to move it; the last dragged position is remembered across restarts and clamped to available screens. Settings can disable position memory or reset it.

- Configurable global shortcut, mouse selection, arrow-key navigation, Return to paste, Command+1 through Command+9 for the first nine results, Escape to dismiss.
- Click the magnifying glass, press Command+F, or start typing to search text and source app. The search row includes a filter menu for pinned items, text, images and files. Searches are debounced and run away from the main thread.
- Pin/unpin, delete individual items, copy without pasting, paste plain text and clear all unpinned items.
- Shift-click or Shift-Return pastes plain text. Settings can make plain text the default.
- Text, HTML, RTF, supported image data, animated GIF data, URLs and multiple file references retain their pasteboard representations. File content is not copied into history; moved/deleted original files may no longer paste.
- Full-resolution original image bytes are stored; history cards use cached thumbnails.
- 250 entries, 32 MB per item and a 256 MB history budget by default. Configurable up to 5,000 entries, 128 MB per item and 4 GB. An optional Windows-compatible preset uses 25 entries and 4 MB per item. Lowering the item limit applies to future captures; existing pins remain protected.
- Old unpinned entries are evicted first. Pins are protected even when limits are reduced. If pins fill the entire budget, incoming items are skipped with an explanatory message. Pinned entries can therefore exceed a newly reduced budget.
- History persists across app restarts by default. This can be disabled for unpinned items.
- Local AES-256-GCM encrypted history, with the encryption key in macOS Keychain. Immutable encrypted payload files and a small authenticated index avoid rewriting the full history on every edit. Files are owner-only, and the private data folder is excluded from future backups. Password managers are excluded by default; concealed, transient and autogenerated pasteboard markers are ignored. App exclusions are configurable. Capture is suspended while the user session is inactive or secure keyboard input is active. These protections depend on source apps marking sensitive content correctly; they do not identify every password copied from a browser.
- Pause/resume capture from Settings or the menu-bar icon's right-click menu.
- Emoji and skin-tone variants use names available on the local Mac. Symbols, kaomoji and recently used characters are searchable. Character Viewer opens the complete native catalogue. The embedded emoji list uses system resource data and falls back to a smaller built-in list if that data is unavailable.
- Personal animated GIF import/library without an account. Online GIF search is implemented using the GIPHY API and requires your own API key, saved in Keychain. The GIF library has a separate 100-item / 256 MB budget. Preview decoding validates dimensions and is serialized; animations with an estimated decoded size above 16 MB show a still thumbnail while the original animated data is retained for pasting. Apps differ in whether they accept pasted animated GIFs; some paste only a still image.
- Optional encrypted text sync through a user-chosen iCloud Drive, OneDrive or other shared folder. Configure the same parent folder and passphrase (minimum 12 characters) on each Mac. PBKDF2-HMAC-SHA256 with 600,000 rounds derives keys for new sync folders. Existing 1.0 folders retain their 210,000-round profile for compatibility. Text up to 1 MB is supported; images and files stay local. Uploads prune validated shared records to a maximum of 250; malformed or unknown files are retained rather than silently deleted. Automatic upload is off by default. The item menu also has manual Sync text. Local pinning/deletion is independent on each Mac; deleting locally does not erase other Macs or the sync folder. Disconnecting removes the saved local sync key and leaves shared files in that folder.
- System, light and dark appearance; native launch-at-login integration.

## Limits of parity

This recreates the Windows workflow with native Mac styling. It does not integrate with Microsoft's private account-based Cloud Clipboard service. Folder sync is a separate feature between copies of Clipboard. Online GIFs require a GIPHY developer key. macOS permissions and the receiving app determine clipboard access and whether automatic paste is accepted. Clipboard polling may miss a value that changes more than once within 450 ms.

## Data and removal

Version 1.2 uses a new app identity and starts with fresh storage and preferences. It does not import data, settings or keys from builds released under the previous name. Those saved files are left untouched. Grant Accessibility permission to Clipboard, set your preferences, and save your GIPHY API key again. For folder sync, configure a new `Clipboard Sync` folder on every Mac using this version; mixed-version sync is not supported.

Encrypted history and GIF data: `~/.local/share/clipboard/`, containing authenticated `history.index` / `gifs.index` manifests and HMAC-named `.clipdata` payloads. A failed authentication or missing key preserves existing data and switches the affected collection to memory-only operation. The displayed capacity limits count raw pasteboard bytes; Base64 encoding, filesystem allocation, indexes and transient decode buffers add overhead.
Preferences: the `local.clipboard.app` user-defaults domain. Keys: macOS Keychain generic passwords under `local.clipboard.app`. Folder sync uses `Clipboard Sync` and encrypted `.clip` records.

To stop, right-click the menu-bar clipboard icon and choose Quit Clipboard. To uninstall, disable Launch at login, quit, and remove the app. If you also want its saved data removed, erase history in Settings first, remove `~/.local/share/clipboard/`, and remove its Keychain entries. A configured sync folder is separate and remains in place.

## Build and validation

```sh
zsh scripts/build.sh
dist/Clipboard.app/Contents/MacOS/Clipboard --self-test
zsh scripts/package.sh
```

The build uses Swift 6 with strict concurrency checking and warnings treated as errors, the installed Apple command-line tools and Apple frameworks; there are no third-party runtime dependencies. The `ViewState` alias selects SwiftUI's property wrapper on SDKs that also expose a State macro unavailable in standalone command-line toolchains.

Self-tests cover history bounds, pinning, duplicates, original bytes, multi-file metadata, encryption, legacy migration, tamper detection, file permissions, symbolic-link rejection, sync input validation, mocked bounded HTTP requests, destination paste policies, position restoration and catalogues. Pasteboard integration checks run only if the operating-system pasteboard service is available, otherwise they are explicitly reported as skipped. Tests use a separately named pasteboard and do not modify the user's general clipboard. `--preview /absolute/path.png` renders a panel containing synthetic demo items without monitoring or storing clipboard content.

The build environment could compile and verify the signed application but could not connect to macOS GUI and pasteboard services. Live panel rendering, global shortcut delivery, focus restoration, automatic paste, Keychain prompts, launch at login, online GIPHY search and two-device folder synchronization require validation from a normal desktop launch. GIPHY search additionally needs an API key. Do not interpret the command-line model tests as verification of those interactions.
